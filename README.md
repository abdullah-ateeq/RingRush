# RingRush

**RingRush** is an exciting, fast-paced Android game built entirely with modern Android development practices, using **Jetpack Compose** for a fully declarative UI and architecture components for robust state management.

## Features

- **100% Jetpack Compose:** Beautifully animated transitions, screens, and game loop rendered using modern Compose UI.
- **Game Engine & Mechanics:** Fast and responsive game loop managing game states, difficulties, and high scores.
- **Immersive Feedback:** Custom audio effects and haptic feedback integration to keep players engaged.
- **Theming & Preferences:** Supports dynamic light and dark themes along with user-customizable settings for sound, haptics, and difficulty modes.
- **Modern Architecture:** MVI/MVVM architectural pattern utilizing Kotlin Coroutines, StateFlows, and ViewModel.
- **Responsive Navigation:** Seamless navigation graph moving smoothly between Splash, Home, Game, Settings, About, and Result screens.

## Tech Stack

- **Language:** [Kotlin](https://kotlinlang.org/)
- **UI Toolkit:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
- **Architecture:** MVVM (ViewModel, StateFlow, Coroutines)
- **Storage:** DataStore / SharedPreferences for game preferences and high score persistence
- **Audio/Haptics:** Native Android sound and vibrator APIs
